# Подключение Moonraker

Сервер отправляет G-code на принтер через HTTP API Moonraker (Klipper).

## 1. Узнайте адрес

Обычно это `http://<ip-принтера>:7125`. Проверить в браузере: `http://192.168.1.50:7125/server/info`.

## 2. API-ключ

Если в `moonraker.conf` включён `api_key`, передайте его в поле «API ключ» диалога принтера. Если сервер MeshVault находится в `trusted_clients`, ключ можно оставить пустым:

```ini
[authorization]
trusted_clients:
  192.168.1.10
```

## 3. Проверка

В Qt-клиенте: «Принтеры» → «Добавить принтер» → укажите имя и адрес → «Проверить». Должно появиться `✓ Connection successful` и состояние Klipper (`ready`).

## 4. Печать

1. Загрузите модель.
2. В карточке модели нажмите «Прикрепить G-code» и выберите файл.
3. Выберите принтер и нажмите «Начать печать».
4. Прогресс и статус смотрите на экране «Очередь печати» — клиент опрашивает сервер каждые 3 секунды.

Сервер вызывает:

- `POST /server/files/upload` (root=gcodes) — загрузка файла;
- `POST /printer/print/start?filename=...` — запуск;
- `GET /printer/objects/query?...` — статус, температуры, прогресс;
- `POST /printer/print/pause|resume|cancel` — управление.

## Безопасность

API-ключ принтера шифруется в БД через Fernet с ключом `MESHVault_SECRET_KEY`. Не используйте значение по умолчанию в реальной эксплуатации. Доступ к серверу в домашней сети рекомендуется ограничить (брандмауэр или VPN).
