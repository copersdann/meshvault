# MeshVault

Локальный каталог 3D-моделей с просмотром, подготовкой и отправкой на печать.

> **Готовый установщик для Windows:** [MeshVault-0.1.1-win64.zip](https://github.com/copersdann/meshvault/releases/download/v0.1.1/MeshVault-0.1.1-win64.zip)
> (распаковать → `setup_server.bat` → `start.bat`). Репозиторий: https://github.com/copersdann/meshvault

- **Сервер на ПК** — FastAPI + SQLite + content-addressed хранилище. База моделей всегда на сервере.
- **Qt Desktop клиент** — QML + Qt Quick 3D, C++ бэкенд, тёмная тема.
- **Печать** — адаптер Moonraker (Klipper): загрузка G-code, запуск, статус, история.
- **Слайсер** — отправка модели в любой установленный слайсер (PrusaSlicer/Orca/Cura/Flashforge); серверный слайсинг не используется.
- **Форматы** — STL, 3MF, OBJ, GLB/glTF, PLY, AMF, STEP/IGES (FreeCAD или CadQuery), G-code, проекты слайсеров.
- **Экспорт** — конвертация модели в STL/OBJ/GLB/PLY/3MF.
- **Корзина** — мягкое удаление и восстановление моделей.
- **Printability** — проверка замкнутости, нависаний, габаритов и соответствия столу принтера.
- **Миниатюры и GLB** — встроенная генерация через trimesh + Pillow, без внешних тяжёлых программ.
- **3D-вьювер** — собственный GLB-парсер (Qt Quick 3D не грузит GLB напрямую), орбита/пан/зум,
  сетка стола, оси, тени, SSAO, габаритный контур, плоские грани и панель тонких настроек.
- **Каталог** — поиск, сортировка (в т.ч. по размеру/статусу/дате), фильтры по коллекциям/категориям/тегам
  в боковой панели, статистика и настройки вида. Карточки показывают габариты, дату, теги
  и признак замкнутости модели.
- **Кастомизация UI (как в Maya)** — кнопки верхней панели включаются/переставляются в диалоге «⚙»,
  левая панель и «Вид каталога» отделяются в отдельные окна кнопкой «⧉», раскладки сохраняются
  в профилях («Профили»). Порядок кнопок, сортировка и вид каталога запоминаются.

## Структура

```
server/            FastAPI API, обработка геометрии, адаптеры принтеров
apps/desktop/      Qt 6 QML клиент (CMake)
apps/android/      Kotlin + Jetpack Compose клиент (Gradle)
docs/              архитектура и настройка Moonraker
data/              БД и блобы (создаётся автоматически)
scripts/           служебные скрипты (упаковка релиза, пересоздание миниатюр)
release/           локальные сборки и ZIP (в git не попадают)
```

## Быстрый старт

### 1. Сервер

Требуется Python 3.10+ и `uv`.

```powershell
cd server
uv venv .venv
uv pip install -e ".[dev]"
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Документация API: `http://localhost:8000/docs`. Проверка: `http://localhost:8000/api/health`.

### Тестовый релиз Windows (без моделей)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\package_release.ps1 -Version 0.1.1 -Shortcut
```

Скрипт собирает в `release\MeshVault-0.1.1-win64\` только программные файлы (exe, Qt Runtime,
исходники сервера и десктопа, документацию, скрипты), исключая `data/`, `*.stl` и другие модели.
Рядом создаётся ZIP, а на рабочем столе — ярлык `MeshVault 0.1.1 (test).lnk`.
В распакованной папке: `setup_server.bat` (создаёт venv и ставит зависимости), `start.bat`
(поднимает сервер и запускает клиент).

### 2. Qt Desktop клиент

Требуется Qt 6.8+ (модули `Quick`, `QuickControls2`, `Quick3D`, `QuickDialogs2`), CMake, Ninja, MSVC.

```powershell
cd apps\desktop
cmd /c build.bat
```
Результат: `C:\tools\meshvault-build\MeshVaultDesktop.exe`. Скрипт сам подключает MSVC, CMake, Ninja и Qt 6.10.3 (`msvc2022_64`).

Клиент по умолчанию подключается к `http://127.0.0.1:8000`. Адрес и токен меняются на экране «Настройки».

Диагностика клиента: `%APPDATA%\MeshVault\MeshVault\meshvault.log` — туда пишутся QML-ошибки
и предупреждения Qt (консольное окно отключено). Файл ротируется при размере более 5 МБ.

### 3. Тесты сервера

```powershell
cd server
.venv\Scripts\python.exe -m pytest -q
```

## Конфигурация

Скопируйте `.env.example` в `.env` в корне проекта:

```powershell
Copy-Item .env.example .env
```

Основные переменные (префикс `MESHVault_`, регистр не важен):

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `MESHVault_DATA_DIR` | каталог БД и блобов | `./data` |
| `MESHVault_API_TOKEN` |Bearer-токен для API | пусто (без авторизации) |
| `MESHVault_SECRET_KEY` | ключ шифрования API-ключей принтеров | `change-me-in-production` |
| `MESHVault_FREECAD_PATH` | путь к FreeCADCmd для STEP/IGES | автоопределение |
| `MESHVault_SLICER_PATH` | путь к GUI-слайсеру для «Открыть в слайсере» | автоопределение |
| `MESHVault_CURAENGINE_PATH` | путь к CuraEngine для слайсинга | пусто |
| `MESHVault_PRUSASLICER_PATH` | путь к PrusaSlicer CLI | пусто |
| `MESHVault_MAX_UPLOAD_MB` | лимит загрузки | `512` |

## Автоимпорт из каталога

В Qt-клиенте: **Настройки → Каталог моделей**. Укажите путь к папке на этом же ПК (например `F:\Models`), сохраните и нажмите «Сканировать сейчас». Сервер:

- рекурсивно обходит папку и берёт все поддерживаемые файлы;
- создаёт теги из имён вложенных папок и расширения (`stl`, `3mf`, …);
- первую папку превращает в коллекцию;
- считает sha256 и пропускает уже импортированные/дубликаты;
- запускает обработку (GLB + миниатюра) в фоне;
- сканирует автоматически каждые N минут (`MESHVault_IMPORT_INTERVAL_MIN`).

API: `GET/PUT /api/import/config`, `POST /api/import/scan`.

Ответ сканирования содержит `found`, `added`, `skipped`, `duplicates`, `errors`.
Дубликаты определяются по SHA-256 и не создают новые модели; в базе для них сохраняется
ссылка на модель-оригинал (`import_files.duplicate_of`).
`POST /api/import/scan?dry_run=true` показывает, что добавится, без записи в базу
(в Qt-клиенте — кнопка «Предпросмотр»).

Зависшие версии можно перезапустить: `POST /api/models/{id}/versions/{v}/retry`
(в карточке модели — кнопка «Повторить» у версии со статусом «ошибка»).

> Если при старте сервера появляется `OpenBLAS error: Memory allocation...`, задайте `OPENBLAS_NUM_THREADS=1` в `.env` или в окружении (уже добавлено в `.env.example`).

## Импорт по ссылке

В правой части верхней панели кнопка **«По ссылке»** открывает поле ввода прямого URL.

- `POST /api/import/url` принимает `url` на STL/3MF/OBJ/GLB/PLY/STEP/ZIP.
- Дубликаты по SHA-256 не создаются; исходный URL сохраняется в карточке модели.
- Внешние каталоги (Thingiverse, Printables, MakerWorld и др.) не интегрируются: разработка идёт локально.

## Печать

Сейчас поддерживается загрузка готового G-code на Moonraker. Слайсинг на сервере — следующий этап (адаптеры CuraEngine / PrusaSlicer уже заложены в конфиг).

См. [docs/MOONRAKER.md](docs/MOONRAKER.md).
